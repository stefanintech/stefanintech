# Stefan Taitano

I build systems for a living and escape plans for fun.

Army veteran. ServiceNow developer and consultant at Cognizant. Slowly getting better at Ruby.

Most days I work on large public-sector ServiceNow platforms — upgrades, integrations, data quality, and the design decisions that keep an instance healthy. Outside of work I am learning Ruby through [The Odin Project](https://www.theodinproject.com/), writing in public, and showing up in the Ruby community before I feel fully ready.
